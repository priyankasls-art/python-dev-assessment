# Python Developer Assessment

## Project Overview
This repository contains solutions to Python development assessment tasks, including Git basics, code style & linting, data structures, OOP, debugging, and API interactions.

## Completed Tasks
- Task 1.2: GitHub Repository Setup & First Branch
- Task 1.3: Code Style & Linting
- Task 2.1: Data Structure & Algorithm Challenges
- Task 2.2: Implement a Book Class (OOP)
- Task 3.1: Fetch and Process API Data

## How to Run the Code
- All Python files can be run with `python <file_name>.py`.
- Ensure you have `requests` library installed (`pip install requests`) for API tasks.
